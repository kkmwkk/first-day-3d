# 첫 출근 · 블록 사옥

입사를 기념해 만든 블록 스타일 3D 체험입니다. 사옥 앞에서 출발해 사원증을 받고, 게이트를 지나 엘리베이터로 내 조직 층의 내 자리까지 걸어갑니다. 자리에 도착하면 동료들과 인사하고 노트북을 받아 오는 첫날 미션이 열립니다.

플레이: https://kkmwkk.github.io/first-day-3d/ (키보드와 마우스가 있는 PC용)

> 개인이 만든 비공식 작품입니다. 회사의 공식 콘텐츠가 아니며, 건물 외관만 공개된 사진을 참고했고 내부는 실제와 무관한 창작입니다.

## 조작

| 키 | 동작 |
|---|---|
| W A S D | 이동 |
| 마우스 | 시점 |
| E 또는 클릭 | 상호작용 |
| Shift / Space | 달리기 / 점프 |
| Esc | 일시정지 |

## 실행과 배포

```
npm install
npm run dev      # http://localhost:5199
npm run deploy   # 빌드해서 GitHub Pages(gh-pages 브랜치)에 올림
```

이름, 조직명, 층은 `src/config.js` 에서 바꿉니다.
